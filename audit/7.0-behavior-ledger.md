# 7.0 行为台账（Breaking & Behavior Changes）

归档于 2026-10-30（两线合流入 `dev-v7` 后定稿）。这是 7.0 相对 6.x 的**全部**已知行为差异清单——发版 CHANGELOG 的底稿。分三类：**A 故意破坏**（7.0 设计目标）、**B 语义变化**（等价替换原则下的可感知差异）、**C 缺陷修复**（6.x 行为本身是 bug，修复后行为不同）。

## A. 故意破坏（Breaking，需要迁移）

| # | 变更 | 迁移 |
|---|---|---|
| A1 | **jQuery 移除**：peerDependencies 只剩 `what-input`；`dist` 零 jQuery 依赖；`addToJquery` / `$.fn.foundation` / `$(el).foundation('method')` 派发全删 | `$(document).foundation()` → `Foundation.init(root?)`；实例方法调用 → `Foundation.Registry.getInstance(el).method()` |
| A2 | **float grid 与旧 flex grid 删除**：`.row`/`.column(s)` 类、`foundation-grid`/`foundation-flex-grid` mixin、`foundation-float` CSS 变体、`foundation-everything` 的 `$flex` 参数全删 | 迁到 xy grid（`grid-container`/`grid-x`/`cell`）；flex 工具类无条件输出 |
| A3 | **`$().foundation()` 时代的事件尾参全量元素化**：所有 `*.zf.*` 事件的 extra 参数从 jQuery 对象改为原生 Element | 消费方按元素使用（`el.classList` 等） |
| A4 | **zf.trigger 局部派发不再到达第三方 jQuery 监听器**：open/toggle 的元素局部派发是真非冒泡 CustomEvent，jQuery 合成事件与原生互不过桥 | 第三方监听改原生 `addEventListener`（或经 Events 层） |
| A5 | **destroy 所有权语义**：插件 `_destroy` 只摘除自己的监听；第三方挂在元素上的 jQuery 监听器**存活**（6.x 因 jQuery 单表共享，销毁时连带清空） | 自理自有监听的第三方代码不再被误伤；依赖 6.x"焦土"行为的需要自行清理 |

## B. 语义变化（等价替换下的可感知差异）

| # | 变更 | 说明 |
|---|---|---|
| B1 | **Triggers 委托武装时点**：window load → **DOMContentLoaded**（或 DOM 已解析立即）。挂起的第三方资源（视频 iframe）不再拖死 data-open/close/toggle 交互 | 交互更早可用；closeme 快照仍见全量插件（init 先于 DCL） |
| B2 | **Magellan 监听武装**：scrollme/resizeme/链接委托由 window load 提前到 DCL；**DCL 时重读链接列表**（侧栏晚注入的导航此时已就位）；load 后保留尺寸复算 | 早于 6.x 可用；晚注入 DOM 的导航现在能被追踪 |
| B3 | **triggerHandler 终形**：真·非冒泡 CustomEvent（跨 bundle 共享传输），`event.result` 经 `zfResult` 回传 | 与 jQuery triggerHandler 的本地性一致，跨表可达是新增能力 |
| B4 | **closeme 广播改真冒泡事件**：`[data-closable]` 祖先会被顺带关闭（6.x jQuery 合成事件不冒泡，不会） | 极端布局下多关一层；Reveal 特征测试已钉 |
| B5 | **fx 动画引擎**：Motion 原生 fx 原语（rAF 逐属性 + swing 余弦），jQuery fx 语义逐条对齐（逐元素队列、duration-0 同步、stop/finish 跳终点）；SmoothScroll/Reveal 完成回调 **2→1 次**、尺寸补间丢弃 | 动画观感一致；依赖双回调的第三方代码需适配 |
| B6 | **Sass：`$primary-color` 前置赋值现在胜出**（6.x 被 palette 派生无条件覆盖） | 多数人视为修复；确属行为变化 |
| B7 | **Sass：@extend 生成选择器序**：模块模式=源序（import 模式=反序）；4 个 dist 资产入口暂留 legacy 流保字节等价，7.0 重定基线时切换 | 自写 @use 入口的输出顺序与 6.x 不同 |
| B8 | **Sass 配置机制（新）**：`foundation-next` 按需引入 + `meta.module-variables()` 反射配置，覆盖**全部 34 个组件**（耦合组件经共享 mixin 参数化解开：`_button-styles`/`_menu-styles` 无 cell 共享模块 + 原模块同名 shim 保公共面 + 读者镜像旋钮） | 详见 `audit/line-b-settings-migration.md`；未知 settings 键编译期 @warn |
| B9 | **data-validator 校验回调第三参**：原生父元素（原来是 jQuery 包装） | 自定义校验器按元素使用 |
| B10 | **`$global-flexbox` 移除**：float grid 删除后分支永真，全部 `@if $global-flexbox` 分支、mixin 线程参数、settings 条目（`$global-flexbox: true`）随之删除；flex 工具类无条件输出 | 设置了该变量的用户在新机制下收到 unknown-key @warn；import 世界多余赋值无害 |
| B11 | **`:animated` 判定**：`Motion.isAnimating(el)`，实现无关 | `$(el).is(':animated')` 用户改用 Registry/实例状态 |

## C. 缺陷修复（6.x 是 bug，行为随之不同）

| # | 修复 |
|---|---|
| C1 | `toElement(window)` 不再把 window 拆成 `window.frames[0]`（跨域 iframe 的 SecurityError 家族根因） |
| C2 | Triggers 委托单次投递：per-plugin bundle 内联副本去重（一次点击 toggle 执行一次，不再是 N 次＝净关闭） |
| C3 | Slider 无 `[data-slider-fill]` 标记不再崩溃（6.x 空集合 no-op 语义恢复） |
| C4 | Abide `matchValidation` 裸 `el` 修复——6.x→7.0 迁移期崩溃，data-validator 现在可用 |
| C5 | OffCanvas destroy 漏摘的无命名空间 transitionend 等待（M1 泄漏家族） |
| C6 | Orbit 单 slide/无 autoPlay destroy 的 TypeError；Sticky 从未绑定的 `change.zf.sticky` off 死行 |
| C7 | 文档站 kitchen-sink 的 Magellan 演示缺失目标区块（文档源码缺陷，非框架） |

## 明确不动的契约

- data 属性 API（`data-open`/`data-close`/`data-toggle`/`data-closable`…）、`*.zf.*` 事件名、`Foundation.<Name>` 导出、`window.Foundation` 全局
- MediaQuery `is()` = atLeast 语义（6.4+ 契约）、断点名
- dist CSS 字节等价（xy 迁移未动输出：default/rtl/prototype 三变体逐字节不变）
- JS dist 仍 ES5（决策 D3），浏览器基线 6.x 口径
